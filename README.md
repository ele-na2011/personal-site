## guestbook setup

The home page guestbook uses Supabase so messages persist for every visitor.

Run this in the Supabase SQL editor:

```sql
create table public.guestbook_messages (
  id bigint generated by default as identity primary key,
  name text not null check (char_length(name) between 1 and 60),
  message text not null check (char_length(message) between 1 and 280),
  created_at timestamptz not null default now()
);

alter table public.guestbook_messages enable row level security;

create policy "Anyone can read guestbook messages"
  on public.guestbook_messages for select
  to anon
  using (true);

create policy "Anyone can add guestbook messages"
  on public.guestbook_messages for insert
  to anon
  with check (true);
```

Then put the project URL and anon key in `SUPABASE_URL` and
`SUPABASE_ANON_KEY` at the top of `script.js`. Use only the anon key in this
browser code; never expose a Supabase service-role key.
